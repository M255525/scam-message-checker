這是什麼

收到怪怪的簡訊或 LINE 訊息，不知道是不是詐騙？把訊息貼進來，按「幫我看看」，就會用紅綠燈告訴您危不危險，還會說明為什麼、接下來該怎麼做。

不用註冊、不用帳號。訊息只在您的手機裡判讀，不會上傳，也不會存起來。

怎麼用

  1. 在可疑的訊息上長按，選「複製」。
  2. 打開本工具，按「📋 貼上」（或長按輸入框選「貼上」）。
  3. 按藍色的「幫我看看」。
  4. 看燈號和說明。不確定就按「☎ 打 165」，或按「💬 用 LINE 傳給家人問問」。

還沒有可疑訊息，可以先按首頁下方的範例按鈕試試看。

用 LINE 傳給家人

  1. 在結果畫面按綠色的「💬 用 LINE 傳給家人問問」。
  2. LINE 會打開，選要傳的家人或家族群組，按「傳送」。

傳出去的內容會附上燈號結果和原本的訊息。訊息裡的連結會自動改成點不開的寫法（例如 hxxps://abc[.]com），家人看得到網址，但不會不小心點進去。

不用 LINE 的話，按「📤 用其他方式傳送」，可以選簡訊、Messenger 等；電腦上會改成複製文字。

用截圖

有些訊息不能複製（例如圖片），可以先截圖，再按「📷 用截圖」選那張圖。手機會自己把圖上的字讀出來。

  • 截圖不會上傳，辨識在手機上做。
  • 第一次要下載文字辨識資料（約 10 MB），建議連 Wi-Fi。
  • 讀出來的字可能有錯，請看一下再按「幫我看看」。

燈號是什麼意思

紅燈很可能是詐騙。不要回覆、不要點連結、不要匯款。打 165 或問家人。
黃燈有可疑的地方。自己打官方電話或開官方 App 查證，不要用訊息裡的電話或連結。
綠燈沒看到常見的詐騙說法。不代表一定安全，對方之後開始談錢、要資料，再查一次。

判斷方式：比對台灣常見的詐騙說法，例如「監管帳戶」「解除分期」「保證獲利」「換號碼借錢」「包裹地址不全補運費」「給我驗證碼」，也會檢查連結是不是縮短網址、假冒政府網址等。

從 LINE 直接分享進來（Android）

先把本工具加入主畫面。之後在 LINE 訊息上長按 →「分享」→ 選「詐騙紅綠燈」，就會直接幫您判讀，不用複製貼上。

常用設定

按右上角 ⚙ 或頁面下方「⚙ 常用設定」。

  • 要問的家人：填家人的稱呼和電話，結果畫面會多一顆「打給家人」的按鈕。
  • 字體大小：大／特大，另有高對比模式。
  • 自動唸結果：開了以後，看完會自動用語音唸出結果。也可以在結果畫面按「🔊 唸給我聽」。
  • 關於本工具：創作者、操作手冊、使用警語、加入主畫面、訪客數。

萬一已經被騙

  1. 馬上打 165 反詐騙專線。遇到緊急危險打 110。
  2. 打給銀行客服，請他們止付、凍結。
  3. 留下對話截圖、匯款單，不要刪掉。
  4. 這不是您的錯，趕快告訴家人一起處理。

加入主畫面

  • Android：按「⚙ 常用設定 → 關於本工具 → 加入主畫面」。
  • iPhone：用 Safari 打開，按下方「分享」圖示，選「加入主畫面」。

使用警語

這是幫忙提醒的參考工具，不能保證判斷正確。綠燈不代表一定安全，紅燈也可能誤判。不確定就打 165。

本工具不是警政署或任何政府機關的服務。訊息與截圖只在您的手機裡處理，不會上傳。
